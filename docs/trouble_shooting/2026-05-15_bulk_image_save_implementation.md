# [2026-05-15] AI 생성 이미지 8종 일괄 저장 기능 구현

## 1. 문제 상황 (Issue)
- 사용자가 생성된 8개의 이미지를 모두 개인 기기에 소장하고 싶어 하지만, 기존에는 한 장씩 수동으로 저장하거나 아예 저장 기능이 제공되지 않아 사용자 경험이 불편했음.
- 인스타그램 공유 기능은 구현되어 있으나, 갤러리(앨범)에 직접 저장하는 기능이 부재함.

## 2. 해결 방안 (Solution)
- **라이브러리 도입**: `gal` (2.3.0) 패키지를 사용하여 iOS/Android 기기의 갤러리에 접근 및 파일 저장 기능 구현.
- **이미지 다운로드 및 일괄 처리**:
  - `dio`를 사용하여 각 이미지 URL로부터 바이트 데이터를 다운로드.
  - `path_provider`를 통해 임시 디렉토리에 저장 후 `Gal.putImage`를 호출하여 앨범으로 복사.
  - 비동기 루프를 통해 8개의 이미지를 연속적으로 저장.
- **사용자 경험(UX) 개선**:
  - 저장 중 버튼에 로딩 애니메이션(`isLoading`) 추가 및 중복 클릭 방지.
  - 갤러리 접근 권한(`Gal.hasAccess`, `Gal.requestAccess`) 처리 로직 추가.
  - 저장 완료 후 성공 개수를 포함한 `SnackBar` 알림 제공.

## 3. 구현 세부 사항
- **Target File**: `lib/presentation/screens/result_view/image_result_view.dart`
- **Method**: `_saveAllImages(List<ImageVariationItem> variations)`

- [x] 권한 거부 시 적절한 안내 메시지가 노출됨을 확인.
- [x] 저장 프로세스 중 버튼이 비활성화되며 로딩 상태가 표시됨을 확인.
